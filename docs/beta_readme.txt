3DYNAMIC FORCE — БЕТА 0.10.6 (Windows)
Ремейк Dynamic Force (оригинал — Mace Dev). Аркадные гонки на 2–4 игроков.

ЗАПУСК
- Распакуйте архив целиком в любую папку и запустите 3DynamicForce.exe.
  Файл libwebrtc_native...dll должен лежать рядом с exe — без него не работает сетевая игра.
- Windows может предупредить «Система Windows защитила ваш компьютер» (игра не подписана):
  «Подробнее» → «Выполнить в любом случае».
- При создании игры брандмауэр Windows спросит доступ к сети — разрешите
  (хотя бы для частных сетей), иначе друзья не подключатся.

УПРАВЛЕНИЕ
- WASD или стрелки — руль, газ, тормоз/назад
- Shift — дрифт: держите в повороте, рулём подправляйте дугу. Чем дольше занос, тем выше
  заряд — искры синие, потом оранжевые, потом фиолетовые; отпустите — ускорение по заряду
- Пробел — парирование (окно 0.4 с: проехать сквозь ограждение, банан, лазер, снежок…)
- Q — предмет из коробки (помидор сам летит в ближайшую машину впереди)
- − / + — общая громкость (как в оригинале)
- Esc — пауза / меню
- Геймпад: стик — руль, RT/A — газ, LT/B — тормоз, RB — дрифт, X — парирование, Y/LB — предмет
- Сенсорный экран: кнопки появляются после касания (или F1)
- Автогаз — в настройках: машина едет сама, тормоз — тормоз и задний ход

ПРЕДМЕТЫ
- Чем ближе к первому месту, тем «спокойнее» предметы из коробок (бананы, бомбы, лёд),
  а отстающим чаще достаются нитро, рывок, лазер и флешка — догнать можно.

ГАРАЖ
- В меню кнопка с машинкой слева — гараж: цвет кузова (кнопки R, G, B), кузов, стёкла, рисунок, колёса — как в оригинале.
  Говорят, если зажать кнопку кузова, выйдет кое-что особенное.
- Друзья видят вашу машину такой, какой вы её собрали.

КАК ИГРАТЬ ВМЕСТЕ
- Один игрок жмёт большую кнопку «играть», выбирает карту и «С ДРУЗЬЯМИ», потом сообщает
  остальным ID игры (5 знаков, кнопка «КОПИРОВАТЬ»).
- Сменить карту можно прямо в лобби: стрелки < > у названия карты (только у хоста).
  Все остаются в игре, ID тот же.
- Остальные в меню жмут кнопку с человечком (снизу слева), вводят ID и «ВОЙТИ». В одной
  локальной сети игра видна там же списком, интернет не нужен. Через интернет — тоже по ID.
- Если включён VPN (в режиме TUN), прямое соединение может не пройти — выключите его на время игры.
- Создатель игры катается со всеми в лобби у старта и жмёт «НАЧАТЬ» (или Enter).
- Во время гонки войти нельзя — ждите лобби.
- Вход через интернет может занять до 30 секунд — подождите.
- Если через интернет не соединяется — нажмите «ПРОВЕРКА СЕТИ» (кнопка с человечком) (оба игрока) и пришлите
  результат. «Строгий NAT» у обоих — попробуйте другой сетью (например, раздать интернет
  с телефона) или пусть игру создаст тот, у кого NAT обычный.

КАРТЫ
Трамплины (наша), Хим. зона, Снежная, Пляж, Стройка, Шинозавод, Аквапарк, Радужная (карта друга).

ЧТО ПРИСЛАТЬ ПОСЛЕ ТЕСТА
- Что сломалось / что неудобно / где застряли (карта, примерное место).
- Если игра упала или вела себя странно — файл журнала:
  %APPDATA%\Godot\app_userdata\3Dynamic Force\logs\godot.log
  (вставьте путь в адресную строку проводника).

ИЗВЕСТНОЕ
- Это бета: часть музыки и звуков временная (из оригинала), перед релизом будет заменена.
- Карта «Цирк» из оригинала не перенесена.
