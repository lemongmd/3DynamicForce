3DYNAMIC FORCE — НАБОР ДЛЯ СВОИХ КАРТ (к бете 0.10.5)

Карты делаются в бесплатном редакторе Godot прямо в проекте игры: панель «Трасса» ставит
объекты ровно на полосы одним кликом, проверяет карту и сразу запускает гонку на ней.

1. УСТАНОВКА (один раз)
   - Скачайте Godot 4.7.2 (обычный, не .NET): https://godotengine.org/download/archive/4.7.2-stable/
     Это один .exe, установка не нужна.
   - Распакуйте этот архив в любую папку.
   - Запустите Godot → «Импорт» → выберите файл project.godot из распакованной папки →
     «Импортировать и редактировать». Первый запуск — 1–2 минуты (Godot готовит картинки).
   - Если Godot попросит перезапуститься (из-за модуля сетевой игры WebRTC) — перезапустите.

2. НОВАЯ КАРТА
   - Справа (или слева) найдите вкладку «Трасса». Внизу панели впишите имя карты латиницей
     (например, vasya_desert), выберите фон и нажмите «Создать и открыть».
   - Форма трассы: выделите узел Path в дереве сцены и двигайте точки (между точками —
     прямые, углы скругляются сами; точка 0 — старт).
   - Объекты: нажмите кнопку объекта на панели и кликайте по дороге. R — повернуть,
     Esc — выйти из режима, Ctrl+Z — отменить.
   - «Проверить карту» — подскажет, где пусто (больше 60 м без объектов), что на стене,
     что наезжает друг на друга. Поставьте хотя бы 3–4 ряда коробок предметов.
   - «▶ Гонка на этой карте» — сохранить и проехать.
   Подробный туториал — docs/map_editor.md (откройте в любом текстовом редакторе).

3. ОТПРАВИТЬ КАРТУ
   - Пришлите один файл: scenes/tracks/<имя_карты>.tscn из папки проекта.
   - Новые картинки, звуки и скрипты не добавляйте — карта должна собираться из того, что
     уже есть в проекте (иначе её не получится добавить в игру как есть).

Советы: у каждой фишки — своё место (трамплин перед рядом ограждений, крутая шпилька под
дрифт, ускорители на выходе из поворотов); 3–4 ряда коробок на круг; знаки — сдержанно.

Внутри набора — ассеты оригинальной Dynamic Force (Mace Dev) и временная музыка/звуки:
только для создания карт, не публикуйте их отдельно.
