# 3Dynamic Force

Ремейк гонок **Dynamic Force** (автор оригинала — Mace Dev) на Godot 4.7.2: мультиплеерные аркадные
гонки с видом сверху, 2–4 игрока по сети.

## Как открыть

1. Установить **Godot 4.7.2** (обычная версия, не .NET).
2. Склонировать репозиторий и открыть `project.godot` в Godot.
3. Первый запуск импортирует ассеты (минуту-другую). После этого один раз перезапустить редактор
   (подхватится сетевое расширение WebRTC).

## Как править карты

Карты — `scenes/tracks/*.tscn`. Открываете сцену карты, справа панель **«Трасса»**: объекты,
ширина и высота дороги, «Проверить карту», «Гонка на этой карте». Подробно — в
[`docs/map_editor.md`](docs/map_editor.md), правила хорошей трассы — в
[`docs/level_design.md`](docs/level_design.md).

Карты оригинала: `map_a` Хим. зона, `map_b` Снежная, `map_d` Пляж, `map_e` Стройка,
`map_f` Шинозавод, `map_g` Аквапарк; наши: `remake_01` Ралли, `map_h` Радужная.
Файлы с `_` в начале (`_rainbow_example.tscn`) — примеры, в игре их нет.

## Совместная работа

- Перед работой — `git pull`, после — коммит и `git push`.
- Чтобы не было конфликтов, договоритесь, кто какую карту правит: одну сцену `.tscn` вдвоём
  одновременно лучше не трогать.
- Проверка карт без редактора:
  `godot --headless --fixed-fps 60 --path . -s res://scripts/tools/map_test.gd`

Всё устройство проекта — в [`CLAUDE.md`](CLAUDE.md).
